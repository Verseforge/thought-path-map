# 思路图

一个轻量的本地思路整理网页。  
从一个起点出发，梳理选择路径，或慢慢理清反复出现的念头，把脑子里的内容摊开来看。

> 当前公开版本为无 AI 基础版。所有内容均由用户主动填写、整理与判断，不提供 AI 分析功能。

## 功能

### 两种整理模式

- **决策推演**：围绕一个问题拆分可能选择，并补充事实与条件、成本、风险、回报，帮助比较不同路径
- **念头整理**：记录反复出现的念头，区分实际观察、主观推测与行动方向，在思绪发散时逐步回到现实与行动

### 结构化思路图

- 从起点逐层延伸分支，支持查看不同层级与同源分支
- 每张卡片最多延伸 3 条分支
- 最多展开至第 5 层级
- 整张图最多保留 39 条分支
- 分支较多时支持折叠详情与悬浮定位导航

### 编辑与复用

- 自动保存在当前浏览器中
- 支持手动保存历史版本、修改版本备注、恢复或删除指定版本
- 支持复制一张已有思路图，用于尝试不同推演方向
- 提供示例模板，可进入体验或基于模板创建新图

### 导出与导入

- 支持导出整张思路图或单条路径的文字版内容
- 支持将本工具导出的标准文字版重新导入为可编辑思路图
- 适合用于不同设备之间迁移，或在双方知情的情况下分享已整理好的图
- 导入时会校验结构、层级、分支数量、字数限制与念头行动规则，避免页面显示混乱或绕开产品限制

### 念头整理中的缓冲支持

- 当念头继续延伸但暂时想不到行动时，可进入更缓和的支持性流程
- 支持将一条念头暂存为“尚未整理”的卡片，之后再继续拆分事实与行动
- 暂存念头计入分支数量，且不能继续向下延伸，避免无限扩大未整理内容

## 使用方式

本项目为单文件静态网页，不需要安装依赖，也不需要后端服务。

1. 直接打开 `index.html` 即可使用
2. 部署至 GitHub Pages 后，可通过网页链接访问
3. 创建的思路图与历史版本默认保存在当前浏览器本地

## 本地数据说明

- 本工具不提供账号登录或云端同步功能
- 不同浏览器、不同设备之间的数据不会自动同步
- 清理浏览器数据后，本地保存的思路图可能无法恢复
- 需要迁移或保留内容时，请提前导出文字版思路图

## 使用边界

本工具用于承载和整理用户主动输入的思路内容，不替用户判断事实是否准确，也不对用户填写、导出或分享的具体内容负责。

请勿使用本工具记录、导出或传播违法、有害或侵害他人权益的信息。
