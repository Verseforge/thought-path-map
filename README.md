# 思路图

一个轻量的本地思路整理网页。  
从一个起点出发，梳理选择路径，或慢慢理清反复出现的念头，把脑子里的内容摊开来看。

> 当前公开版本为 BYOK AI 分析版。  
> AI 分析功能需要用户自行提供 API Key；本站 AI 入口敬请期待。

## 功能

### 两种整理模式

- **决策推演**：围绕一个问题拆分可能选择，并补充事实与条件、成本、风险、回报，帮助比较不同路径
- **念头整理**：记录反复出现的念头，区分实际观察、主观推测与行动方向，在思绪发散时逐步回到现实与行动

### 结构化思路图

- 从起点逐层延伸分支，支持查看不同层级与同源分支
- 每张卡片最多延伸 3 条分支
- 最多展开至第 5 层级
- 整张图最多保留 39 条分支
- 分支较多时支持折叠详情与悬浮定位导航

### 编辑与复用

- 自动保存在当前浏览器中
- 支持手动保存历史版本、修改版本备注、恢复或删除指定版本
- 支持复制一张已有思路图，用于尝试不同推演方向
- 提供示例模板，可进入体验或基于模板创建新图

### 导出与导入

- 支持导出整张思路图或单条路径的分享文字版
- 支持导出「可导入数据包」，用于恢复为可编辑思路图
- 支持复制数据包，也支持下载或上传 TXT 文件
- 适合用于不同设备之间迁移，或在双方知情的情况下分享已整理好的图
- 导入时会校验结构、层级、分支数量、字数限制与念头行动规则，避免页面显示混乱或绕开产品限制

### 念头整理中的缓冲支持

- 当念头继续延伸但暂时想不到行动时，可进入更缓和的支持性流程
- 支持将一条念头暂存为“尚未整理”的卡片，之后再继续拆分事实与行动
- 暂存念头计入分支数量，且不能继续向下延伸，避免无限扩大未整理内容

### AI 分析师（BYOK）

- 支持使用用户自己的 API Key 调用外部 AI 服务
- 当前可选服务商：
  - DeepSeek（默认）
  - 月之暗面 Kimi
  - 智谱 AI 开放平台
  - 阿里云百炼
  - 兼容 OpenAI 接口
- 每个服务商会预填接口地址、API 路径和参考模型名称，也可以自行修改
- 开始分析前会先进行连接测试，并在正式生成报告前进行内容预检
- 决策推演报告侧重识别判断问题、待确认信息与可先验证的一步
- 念头整理报告侧重区分事实、推测与反复缠住的担心，并以更温和的方式给出可开始的小行动
- 对明显不适合分析、提示词攻击、无意义内容、危机心理或自我伤害相关内容，会进行拦截或显示支持性提示，而不是继续生成普通分析报告

## 使用方式

本项目为单文件静态网页，不需要安装依赖，也不需要后端服务。

1. 直接打开 `index.html` 即可使用
2. 部署至 GitHub Pages 后，可通过网页链接访问
3. 创建的思路图与历史版本默认保存在当前浏览器本地
4. 如需使用 AI 分析功能，请在页面内选择「自备 AI」，并填写自己的 API Key 与模型配置

## 本地数据说明

- 本工具不提供账号登录或云端同步功能
- 不同浏览器、不同设备之间的数据不会自动同步
- 清理浏览器数据后，本地保存的思路图和历史报告可能无法恢复
- 需要迁移或保留内容时，请提前导出分享文字版或可导入数据包
- BYOK 模式下，API Key 仅用于当前页面请求；离开页面即清除，不保存密钥

## AI 使用边界

AI 分析仅基于用户填写的思路图内容，帮助整理结构、指出可能缺口或分辨事实与推测，不会自动修改原图，也不替用户做最终判断。

本工具不是心理咨询、医疗建议、法律建议、财务建议或其他专业意见服务。涉及现实风险、身体健康、心理危机、法律财务责任等事项时，请以现实核实和专业支持为准。

本站 AI 入口敬请期待。当前公开版本仅提供 BYOK 分析方式，调用费用、额度和接口规则由用户所使用的模型服务商决定。

## 使用边界

本工具用于承载和整理用户主动输入的思路内容，不替用户判断事实是否准确，也不对用户填写、导出或分享的具体内容负责。

请勿使用本工具记录、导出或传播违法、有害或侵害他人权益的信息。
